## Workflow

Identify the process and permitted launch or attach operation. Check actual ABI and bridge availability. Exported addresses are NativePointer objects; call through a typed NativeFunction and allocate native replacement strings. Bound memory reads. Select Java overloads and observe late modules. CLI-host bridges differ from autonomous Gadget bundles. Retain evidence and clean up; persistent results need a separate patch.

Use supplied or explicitly scoped targets. Example commands do not authorize unrelated actions. Record tool versions, artifact hashes, observations, limitations and verification actually performed. A successful parser, schema check or byte edit does not verify an entire procedure.
